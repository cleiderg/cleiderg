## Featured Project

**[Lantern](https://github.com/cleiderg/lantern)** is a local heartbeat daemon that watches a code repository, files issues as tickets, and hands fixes to AI agents. On a schedule, it reads the logs, bug reports, and test results, writes down anything that looks wrong, and decides what an AI agent can safely fix on its own. Anything risky waits for a person. Every fix arrives as a draft pull request, built in its own sandbox, and the agents are never allowed to push to `main`.

Unlike most AI coding agents, which start every session from scratch, Lantern keeps persistent memory in a SQLite database, allowing it to look up how similar bugs were fixed in the past and skip issues that aren’t worth a developer’s attention.
