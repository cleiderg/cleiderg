## Featured Project

**[Lantern](https://github.com/cleiderg/lantern)** is a local heartbeat daemon that watches a code repository, files issues as tickets, and hands fixes to AI agents. On a schedule, it scans logs, bug reports, and test results, files what it finds as tickets, and fixes what’s safe, leaving anything risky for a person. Every fix arrives as a draft pull request, built in its own sandbox, where agents are never allowed to push to `main`. Unlike most AI coding agents, it keeps persistent memory in a SQLite database, so it can learn from past fixes and skip issues that aren’t worth a developer’s time.
